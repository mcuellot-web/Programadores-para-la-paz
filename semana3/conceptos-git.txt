Repositorio:
Un repositorio es un espacio donde se almacenan los archivos y cambios de un proyecto. Permite organizar el trabajo y mantener un historial de modificaciones realizadas durante el desarrollo.

Commit:
Un commit es un registro de los cambios realizados en un proyecto. Sirve para guardar versiones del trabajo y facilitar el seguimiento de las modificaciones hechas por los desarrolladores.

Push:
El comando push se utiliza para enviar los cambios del repositorio local hacia un repositorio remoto como GitHub. Esto permite compartir el proyecto y mantenerlo actualizado en línea.
