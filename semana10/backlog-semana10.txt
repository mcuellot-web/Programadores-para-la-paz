Backlog del proyecto — Sistema de reportes comunitarios
Historias de usuario ordenadas de mayor a menor prioridad:

1. (Alta) Como ciudadano quiero registrar una incidencia con tipo y descripción para
   dejar evidencia del problema y que pueda ser atendido por las autoridades competentes.

2. (Alta) Como coordinador quiero recibir una alerta automática en Telegram cuando se
   registre un nuevo reporte para poder revisar el caso a tiempo sin necesidad de
   consultar manualmente el sistema.

3. (Media) Como miembro del equipo quiero consultar la lista de reportes registrados
   para hacer seguimiento al estado de cada incidencia y verificar cuáles han sido
   atendidas.

4. (Media) Como ciudadano quiero recibir una confirmación cuando mi reporte es registrado
   para saber que el sistema lo recibió correctamente y no quede en el vacío.

5. (Baja) Como administrador quiero poder filtrar los reportes por tipo de incidencia
   para generar estadísticas y priorizar las intervenciones según la frecuencia de
   cada categoría.
